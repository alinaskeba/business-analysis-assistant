conditions, conflicting confirmation rules, roles and duties. All versions belong to the same dev family.

The original brief.txt and all original run artifacts remain unchanged as historical Ukrainian inputs/results:
- baseline.model-result.json is the first captured live response under schema v1.
- baseline.schema.json, baseline.instructions.txt and baseline.run.json record that run.

The first captured baseline is not a reconstruction of the user's earlier unavailable terminal output.

artifacts are stored; no API key is included. [Initial review](review.md) and [team variant](with-team/review.md)
document historical findings. Translation never turns a stored Ukrainian response into an English run.
