# Dev-кейс 001: переговорки

`brief.txt` — незмінений вигаданий бриф із початкового прототипу.

- `baseline.model-result.json` — початковий результат, реально отриманий із Gemini за схемою v1.
- `baseline.schema.json`, `baseline.instructions.txt`, `baseline.run.json` — схема, інструкції та походження цього запуску.
- `analysis.model-result.json` — відповідь Gemini за розширеною схемою v2, що пройшла Python-валідацію.
- `analysis.schema.json`, `analysis.instructions.txt`, `analysis.run.json` — схема, інструкції, модель, час отримання та SHA-256 нормалізованого брифу.

Початковий результат — перший збережений запуск під час створення кейсу. Раніша
відповідь із термінала користувача була недоступна й не відтворюється як історичний факт.
Результати моделі не редагуються вручну й не є погодженою специфікацією.
Збережені лише вигаданий бриф, відповіді та налаштування аналізу; ключа тут немає.

Під час ручного перегляду перевіряйте: мету зменшення накладок, ролі співробітника,
адміністратора та офіс-менеджера; дві окремі вимоги про підтвердження;
зв'язок конфлікту з їхніми ID та питання, яке блокує специфікацію.
Команду розробки бриф не називає: її ролі не слід вигадувати.
